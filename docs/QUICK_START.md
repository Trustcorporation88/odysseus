# 🚀 Odysseus Quick Start (5 minutes)

Get up and running with Odysseus in 5 minutes.

---

## Step 1: Login (1 min)

1. Go to `https://odysseus-uo9n.onrender.com`
2. Login with credentials (or register)
3. You're in! 🎉

---

## Step 2: Set Up a Model (2 min)

### Option A: Use Existing Model (Easiest)
1. Go to **Settings → API Endpoints**
2. Click **+ Add Endpoint**
3. Select provider (OpenAI, DeepSeek, etc.)
4. Paste your API key
5. Click **Save**

### Option B: Run Local Model (Free)
1. Go to **Cookbook**
2. Click **Scan Hardware**
3. See recommended models
4. Click **Download** next to a model
5. Click **Serve** when done
6. Use it in Chat (it auto-detects)

---

## Step 3: Start Chatting (1 min)

1. Go to **Chat**
2. Type a message: `"Hello! What can you help with?"`
3. Press **Enter**
4. AI responds instantly 💬

---

## Step 4: Try Agent (1 min)

1. Go to **Agent**
2. Ask it: `"Create a file called hello.txt with 'Hello World' in it"`
3. Watch it execute
4. Check your files — it created the file! 🤖

---

## Done! 🎉

Now explore:
- **Documents** — write with AI assist
- **Memory** — teach Agent about you
- **Calendar** — add events
- **Email** — connect your inbox (optional)
- **Deep Research** — ask complex questions
