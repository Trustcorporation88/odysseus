# 🚀 Odysseus Início Rápido (5 minutos)

Comece a usar Odysseus em 5 minutos.

---

## Passo 1: Faça Login (1 min)

1. Vá para `https://odysseus-uo9n.onrender.com`
2. Faça login com suas credenciais (ou se registre)
3. Pronto! 🎉

---

## Passo 2: Configure um Modelo (2 min)

### Opção A: Use Modelo Existente (Mais Fácil)
1. Vá para **Configurações → API Endpoints**
2. Clique **+ Adicionar Endpoint**
3. Selecione provider (OpenAI, DeepSeek, etc.)
4. Cole sua API key
5. Clique **Salvar**

### Opção B: Execute Modelo Local (Grátis)
1. Vá para **Cookbook**
2. Clique **Escanear Hardware**
3. Veja modelos recomendados
4. Clique **Download** ao lado do modelo
5. Clique **Servir** quando pronto
6. Use em Chat (detecta automaticamente)

---

## Passo 3: Comece a Conversar (1 min)

1. Vá para **Chat**
2. Digite uma mensagem: `"Olá! Como você pode me ajudar?"`
3. Pressione **Enter**
4. IA responde instantaneamente 💬

---

## Passo 4: Tente Agent (1 min)

1. Vá para **Agent**
2. Peça: `"Crie um arquivo chamado ola.txt com 'Olá Mundo' dentro"`
3. Veja executando
4. Verifique seus arquivos — foi criado! 🤖

---

## Pronto! 🎉

Agora explore:
- **Documents** — escreva com assistência de IA
- **Memory** — ensine Agent sobre você
- **Calendar** — adicione eventos
- **Email** — conecte sua caixa de entrada (opcional)
- **Deep Research** — faça perguntas complexas
