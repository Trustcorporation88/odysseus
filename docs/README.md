## 🔍 Quick Reference

### Common Tasks

**Chat with AI:**
1. Go to Chat
2. Select model
3. Type message
4. Get response

**Automate a task:**
1. Go to Agent
2. Describe what you want
3. Review execution
4. AI completes it

**Download a model:**
1. Go to Cookbook
2. Click "Scan Hardware"
3. Click "Download"
4. Click "Serve"

**Create a todo:**
1. Go to Notes & Tasks
2. Click "+ New Task"
3. Add items + due date
4. Save

**Sync calendar:**
1. Go to Settings → Calendar
2. Click "+ Add Calendar"
3. Choose provider
4. Grant access
