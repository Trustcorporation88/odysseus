# Deep Research Service

## Overview

**Deep Research** is your multi-step research assistant. It:
1. Understands your question
2. Searches for sources
3. Reads & synthesizes content
4. Generates visual report with citations

Perfect for complex, in-depth analysis.

---

## Getting Started

1. Go to **Deep Research**
2. Ask a research question
3. Let it work (2-5 minutes)
4. Review report with sources

Example questions:
```
"Compare the top 3 NoSQL databases for real-time applications"
"What are the latest developments in quantum computing?"
"Analyze market trends in AI startups in 2025-2026"
"How do transformer models work? Explain deeply with research"
```

---

## How It Works

1. **Parse question** — understand what you're asking
2. **Search web** — find relevant sources
3. **Read sources** — gather information
4. **Synthesize** — combine findings
5. **Report** — create visual summary
6. **Save** — store findings for later

---

## Report Contents

### Overview
- Summary of findings
- Key takeaways
- Confidence level

### Main Sections
- Organized by theme/topic
- Evidence-backed claims
- Direct quotes from sources

### Citations
- Links to original sources
- Source credibility
- Quote context

### Recommendations
- Actionable insights
- Next steps
- Further reading

## Export & Share

### Save Report

- Can be revisited anytime

### Export Formats

- **PDF** — visual report with images
- **HTML** — shareable web page

### Share
- Email link
- Download and send
- Print to PDF

## Tips

### Ask Clearly
- ❌ "AI safety"
- ✅ "What are the current approaches to AI safety in large language models?"

### Specific Topics
- ❌ "Business trends"
- ✅ "How are enterprise companies adopting AI in 2025-2026?"

### Research Quality
- ✅ Ask for recent research (2025-2026)
- ✅ Request multiple perspectives
- ✅ Ask for critical analysis

### Detailed Findings
```
Example:
"Compare TypeScript vs Rust for systems programming.
Include:
- Performance metrics
- Learning curve
- Community size
- Best use cases
- Recent developments"
```

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Research incomplete | Wait longer, try again |
| Wrong focus | Rephrase question more clearly |
| Missing sources | Search term too niche, try broader |
| Bad citations | Check source credibility in links |

## Settings

**Settings → Research Preferences**

- **Search engine** — SearXNG or other
- **Source count** — how many sources to read
- **Synthesis depth** — detail level
- **Auto-save** — save findings automatically
